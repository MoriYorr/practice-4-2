# Практика 4.2. Наблюдения

## Запуск после клонирования

1. Выполните `npm ci` в папке проекта.
2. Скопируйте `.env.example` в `.env.local` и укажите полный URL своего ресурса `books` в `VITE_BOOKS_API_URL`.
3. Выполните `npm run dev` и откройте адрес из строки `Local`.

## Подтверждение запросов

Личный адрес ресурса хранится в `.env.local` под именем `VITE_BOOKS_API_URL`. В таблице `API_URL` обозначает этот полный адрес, который заканчивается на `/api/books`.

| Действие в интерфейсе | Метод | URL | Статус | Тело ответа |
| :--- | :--- | :--- | :--- | :--- |
| Загрузить каталог | GET | `API_URL` | 200 | Массив книг. В начале проверки в нём была одна демо-книга. |
| Добавить книгу | POST | `API_URL` | 201 | Созданная книга с присвоенным сервером строковым `id`. |
| Удалить книгу | DELETE | `API_URL/2` | 200 | MockAPI вернул объект удалённой книги. Приложению достаточно проверить статус. |

Добавление и удаление проверены через форму и кнопку в браузере. Статусы и тела ответов записаны при повторении тех же операций через функции из `api.ts`.

## Четыре эксперимента

1. С неправильным адресом `/api/books123` и без проверки `response.ok` сервер вернул 404 и JSON-строку `"Not found"`, поэтому приложение дошло до `dtos.map` и показало `dtos.map is not a function` вместо понятного `HTTP 404`.
2. Без `await` в `dtos` оказался Promise, поэтому вызов `dtos.map` завершился ошибкой `dtos.map is not a function`.
3. Без `Content-Type: application/json` MockAPI вернул 201, но создал книгу со значениями по умолчанию (`"title 2"`, `"author 2"`) вместо данных запроса. Экспериментальная запись удалена.
4. С `authors: dto.author` компилятор остановился в `src/api.ts`: строку нельзя присвоить полю типа `string[]`. Это защищает интерфейс, который вызывает у `authors` метод массива `join`.

## Ответы на вопросы 13–17

13. Пустой ресурс вернул `[]`. После добавления демо-книги через редактор MockAPI ресурс вернул `[{"id":"1","title":"TypeScript Guide","author":"John Doe","year":2024,"rating":5}]`.
14. Кнопка удаления отправляет `DELETE` на адрес ресурса плюс `/id`. Для тестовой книги запрос ушёл на `API_URL/2` со статусом 200.
15. Запрос на создание книги вернул статус 201 Created.
16. Книга осталась после перезагрузки, отобразилась в JSON самого ресурса и появилась в каталоге на `localhost` после добавления через `127.0.0.1`. У этих адресов разные хранилища браузера.
17. CORS позволяет серверу указать, с каких других сайтов браузер может читать его ответы. Запросы из локального каталога прошли, а предварительный запрос OPTIONS вернул 204 с `Access-Control-Allow-Origin: *` и разрешённым заголовком `content-type`.
